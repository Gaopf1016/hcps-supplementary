# HCPS: Heuristic Candidate-space Policy Search for Agile Earth Observation Satellite Scheduling

## English

This repository contains the supplementary material for the PPSN 2026 paper:

**HCPS: Heuristic Candidate-space Policy Search for Agile Earth Observation Satellite Scheduling**

### Files

- `Supplementary Material for HCPS.pdf` – the main supplementary document, including:
  - Table S1: Keplerian elements of the six satellites used in the experiments.
  - Table S2: Full performance comparison (mean ± std) over all 15 problem scales (100–1500 targets) for all compared algorithms.

### Code and Test Data

The source code and test instances used in this paper are not publicly available at this time.  
Researchers interested in reproducing or extending the results may contact the author:

## 中文

本仓库提供了 PPSN 2026 论文的补充材料：

**HCPS：面向敏捷对地观测卫星调度的启发式候选空间策略搜索**

### 文件说明

- `Supplementary Material for HCPS.pdf` – 主要补充材料，包含：
  - 表 S1：实验中使用的六颗卫星的 Kepler 轨道参数；
  - 表 S2：所有 15 个问题规模（100–1500 个目标）下各对比算法的完整性能对比（均值 ± 标准差）。
